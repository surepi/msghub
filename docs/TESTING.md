# MsgHub 功能验证

## 接口回归

安装 requirements.txt 的依赖后执行：

```bash
python3 -m unittest discover -s tests -v
```

也可使用已有镜像，无需把测试依赖安装到宿主机：

```bash
docker run --rm \
  --mount type=bind,source="$PWD/tests",target=/srv/tests,readonly \
  msghub:latest python -m unittest discover -s tests -v
```

接口测试会自行创建临时数据库、启动独立 Uvicorn 子进程，并关闭 QQ 集成；QQ 队列测试使用临时数据库和 FakeQQ 客户端模拟接口。不会读取线上数据、管理员密码或机器人密钥，不会向真实 QQ 发消息。

覆盖内容：

- 快捷回复增删改查、全局/站点范围、空内容及长度限制、无效站点、鉴权。
- 备注追加和重新读取；访客在线及重连时都收不到备注。
- 添加备注不改变聊天消息、未读、会话状态或最后一条消息。
- 站点删除后的模板级联清理，重复执行数据库初始化。
- 标签名称校验、重复冲突、预设删除后重启不再生成、所有标签接口鉴权。
- 单条/批量添加和移除、重复请求、无效批次原子性、保留其他标签、标签和站点删除后的关联清理。
- 标签与站点/状态/关键词组合筛选和分页计数；重命名同步、删除标签保留消息。
- 管理员实时事件；访客在线及重连时的标签隐私；修改标签不改变未读和会话状态。
- 完整历史文字搜索、编号/访客/联系方式、字面通配符、超长查询限制；站点/标签/状态/日期组合筛选、整天边界、无效日期和分页计数；搜索不改变未读。
- 消息前后游标、历史命中上下文、500 条之前的消息定位；拒绝跨会话消息 ID、无效定位及未登录读取。
- 留言详情和关联列表鉴权、同站点关联隔离、分页、独立留言与失效引用；会话删除保留留言及备注，站点删除级联清理；查看/处理关联留言不改变聊天状态及未读。
- 实际离线转留言和重复追加合并、后台变更事件、公开提交不能伪造关联、访客在线及重连时的处理备注隐私；标记已读不覆盖已处理状态。
- QQ 记录列表/详情/操作鉴权、筛选与分页校验、原始收件人隐私、人工确认无虚构 QQ 编号、禁用时拒绝补发及会话级联清理。
- FakeQQ 覆盖长文部分失败、并发自动/手动补发、引用映射、图片失败不重发文字及格式降级、指数退避/冷却、超时/服务异常/缺失回执暂停重发、显式补发/人工确认、重启与本地保存异常恢复、绑定变更取消、绑定码并发消费、错误脱敏和其他会话继续投递。
- QQ 双向可靠性回归覆盖签名回调提交后才确认、相同消息跨回调编号去重、广播中断后保留已提交回复、批量文字/图片写入异常回滚、重试时保持原目标、旧绑定事件取消、引用歧义被拦截，以及在消息广播和 hook 前中断时仍可扫描到待转发消息。
- 转人工通知覆盖 AI 转人工/异常、离线忙碌/超时、原话摘录与图片/长度限制、内部备注隐私、引用定位、批次去重和留言追加、归档/通知/进度原子回滚、AI 等待期间客服接管、通知与访客转发互不阻塞、无 pending 访客消息的通知自动恢复、人工确认、解绑取消及过时通知停止补发；旧投递表幂等升级。
- 类型与状态/会话组合筛选、来源消息与留言读取、内部事件标识/收件人隐私、来源留言删除置空、级联清理。
- AI 检索的全局/本站隔离、问答与网页结构化快照、长片段截取和总长度限制；回答/分类/资料与实际模型输入一致、资料删除后快照保留、内部备注不进入模型。
- AI 回答、处理记录、归档/通知/进度原子提交与失败回滚；分类标记兼容/隐藏、错误快照不保存服务商错误/密钥、问题截短、旧表初始化兼容及级联清理。
- 记录接口鉴权、会话/消息/投递归属、分页和旧 AI 消息无快照；AI 测试通过临时本机 HTTP 服务验证实际请求及错误脱敏，不使用真实模型服务。实际离线 AI 应答的管理员专用事件、访客在线与重连隐私。

- 会话总结通过临时本机 HTTP 模型服务验证真实请求序列化、模型结果/访客原话校验、接口鉴权/归属/禁用、管理员专用事件、访客在线与重连隐私和错误脱敏；不修改访客联系方式。
- FakeQQ/模拟模型覆盖自动总结与转人工事务回滚、通知固定快照与补发、非法/虚构联系方式丢弃、原话快照保留、重复请求复用、失败重试、并发/新增消息过期、客服接管期间不发过时通知、输入限量/图片标记、私有来源隔离、QQ 总结指令和级联清理。

- AI 接待时机覆盖工作时间内几秒响应、连发合并、模型超时转人工、慢总结不阻塞交接、人工回复接管、访客继续补充和结束后开启新一轮。浏览器使用模拟实时事件验证挂件的接待、处理中和等待人工状态。

## 浏览器验收

仅对临时容器运行，固定使用本机 20101 端口和测试专用密码。不要把线上数据库挂载到验收容器。

```bash
docker run --detach --name msghub-acceptance \
  --publish 127.0.0.1:20101:20100 \
  --env DATA_DIR=/tmp/acceptance \
  --env ADMIN_PASSWORD=acceptance-only \
  msghub:latest

npm install --prefix /tmp/msghub-browser playwright
/tmp/msghub-browser/node_modules/.bin/playwright install --with-deps chromium
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_acceptance.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_tags.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_search.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_links.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_qq_delivery.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_handoff.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_ai_evidence.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_summaries.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_triage.cjs
NODE_PATH=/tmp/msghub-browser/node_modules node tests/browser_web_states.cjs
docker stop msghub-acceptance
docker rm msghub-acceptance
```

脚本创建独立测试站点，结束时清理自己创建的站点和模板。覆盖模板表单、站点可用范围、插入不自动发送、备注持久化和 HTML 转义、会话切换期间的延迟响应、窄屏导航和输入区、挂件首次收起及展开、退出后清空会话。

标签脚本另覆盖标签管理及 HTML 转义、勾选会话不打开聊天、单条/批量添加和移除、筛选后实时移出及空状态、两个独立后台窗口同步、断线重连恢复、回复/备注草稿保留、长标签和手机筛选/批量控件可见性。

搜索脚本仅通过 `docker exec msghub-acceptance` 在临时数据库中建立 35 个会话和一段超过 600 条的聊天历史，写入前检查临时数据目录与测试密码。覆盖分页/实时排序、组合筛选、命中转义和滚动定位、历史加载、草稿保留、迟到响应隔离、历史快照期间新消息不丢失及桌面/手机布局。

关联脚本同样只向临时容器写入测试数据，覆盖双向跳转、关联分页和主列表当前页之外的详情、处理状态独立、双窗口实时更新、草稿保留、HTML 转义、独立/来源删除状态、关闭弹层期间的迟到响应，以及桌面/手机布局。

QQ 记录脚本向临时容器写入 25 条模拟投递，覆盖分页/筛选/详情、HTML 转义、QQ 禁用时补发失败、发送期间按钮锁定、未确认结果提示、真实人工确认接口、取消状态、迟到响应隔离与三种屏幕尺寸。浏览器补发等待场景使用模拟 HTTP 响应；真实发送流程由 FakeQQ 后端测试覆盖。

转人工脚本通过无网络的入队函数在临时容器创建两条模拟通知，覆盖类型/状态筛选、原因/原话摘录/HTML 转义、内部备注不混入、来源对话与留言跳转、草稿保留、来源删除、人工确认和三种屏幕尺寸。

AI 依据脚本通过无网络的存档函数创建模拟记录，覆盖分页、AI 消息与投递定位、原资料删除后的快照、问答/网页来源、HTML 转义和危险网址不生成链接、无资料与旧消息、草稿保留、关闭/重开后的迟到响应、AI 测试页结构化展示及桌面/手机布局。测试页浏览器响应使用模拟 HTTP 内容，实际模型接口序列化由上述本机服务回归覆盖。十套浏览器脚本需顺序运行；测试站点和标签在退出时清理，不使用线上配置。

截图默认保存到 /tmp/msghub-browser，可用 MSGHUB_TEST_ARTIFACTS 指定其他目录。当前检查尺寸为 1440×900、390×844、320×568；手机软键盘、真实设备及非 Chromium 浏览器需另行验收。

总结脚本通过无网络存档函数在临时数据库建立总结，覆盖成功/失败/空态、历史快照与过期提示、访客原话/HTML 转义、生成/更新与关闭切换期间迟到响应、回复草稿、QQ 通知对应快照入口，以及 1440/390/320 像素布局。浏览器生成成功使用模拟 HTTP 响应；真实模型请求与提取校验由临时本机服务和 FakeQQ 回归覆盖。

分类测试使用本机模拟模型接口、FakeQQ 和临时数据库，覆盖类别枚举/访客原话/标签目录校验，接管前后高优先级、原始错误脱敏、自动标签/提醒同事务回滚、固定快照/补发/引用、独立投递流、去重冷却、人工屏蔽与改名、过期分析、慢模型期间新消息/回复/关闭/撤销/更换绑定、任务合并/退避/重启兼容、QQ 指令、筛选鉴权/归属、真实后台事件与访客在线/重连隐私，以及级联清理。

分类浏览器脚本仅在隔离容器创建分析快照和模拟 QQ 记录，覆盖分类/高优先级组合筛选和标记、原话/标签 HTML 转义、真实应用标签与撤销接口、回复草稿、空态/配置错误、迟到响应隔离、QQ 记录到分类快照跳转、两个 AI 开关保存及 1440/390/320 像素布局。手动生成成功由上述本机模型接口测试覆盖。

网页状态脚本覆盖单个接口慢请求和错误重试、后台实时连接恢复后补齐消息且保留草稿、访客消息送达未确认和取回原文、上传及表单失败、资料提交、320/390 像素留言列表，以及模拟软键盘收窄可见窗口。可设置 `MSGHUB_BROWSER=firefox` 或 `MSGHUB_BROWSER=webkit` 在安装对应浏览器及依赖后复验。真实手机键盘仍需真机检查。
